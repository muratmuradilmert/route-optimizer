API Ayarları

API anahtarı yalnızca Google Maps haritası için kullanılır. Rota istekleri, uygulama Baslat.bat (yerel sunucu) ile açıldığında klasördeki servis hesabı anahtarıyla gönderilir; bu durumda proje kimliği ve belirteç gerekmez. Sunucusuz kullanımda (ör. GitHub Pages) proje kimliğini ve "gcloud auth print-access-token" ile alınan belirteci girin. Belirteç yaklaşık 1 saat geçerlidir ve saklanmaz.
